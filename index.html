What I've built 01 · four projects

Small Practice Security Kit

Public · GitHub

Most small practices have no idea where they stand on HIPAA until an audit or an incident forces the question. This toolkit maps out a practice's ePHI flows, vendor and BAA status, MFA and access gaps, and AI usage, then generates a remediation packet the owner can actually use, with a 30/60/90 day plan.

The outputs are deterministic and avoid PHI by design, so you can hand a packet to an auditor, insurer, or MSP without worrying about what's inside it.

Python · Flask · Google Workspace / M365 metadata connectors · YAML/JSON validation

Security Operations Triage Pipeline

Public · GitHub

I wanted to understand how a SOC decides what to work on first, so I built that decision process myself. The pipeline takes alert exports, vulnerability records, CISA KEV data, and asset inventory, scores everything with consistent rules (ransomware relevance, internet exposure, ePHI impact, false positive overrides), and outputs prioritized tickets with MITRE ATT&CK mappings.

My favorite part is the handoff. Every bundle ships with SHA-256 integrity manifests and AES-256-GCM encryption, so the transfer from analyst to owner is defensible.

Python · pytest · MITRE ATT&CK · CSV/JSON/HTML/PDF reporting

Velari Secure Practice OS

Private · demo on request

The biggest thing I've built. A full security workspace for practices that don't have a security team: systems inventory, ePHI flow mapping, vendor and BAA tracking, access reviews, downtime planning, risk treatment, and encrypted evidence management. Everything runs locally with no cloud dependency.

One rule I held the whole way through: a practice manager should be able to run their entire security program and produce packets for MSPs, risk assessments, and insurance reviews without uploading patient data anywhere.

TypeScript · React · Vite · WebCrypto AES-GCM

PHI Guardrails for AI Agents

Public · GitHub

Healthcare orgs are adopting AI faster than their policies can keep up, and most "AI safety" is a document nobody enforces. I built actual controls: checks on role, purpose of use, BAA status, sensitivity tier, and PHI patterns that run before an agent executes, with block, redact, or proceed paths and structured audit logs.

The idea was to show that minimum necessary access can be enforced in code, with evidence a reviewer can follow, instead of promised in a policy PDF.

Python · Strands Agents · RBAC · audit logging
