Cloud IAM Access Review Analyzer

Google Workspace, Entra ID and AWS each only show their own accounts. When someone leaves, it's easy to remove their email and miss their AWS access. This Python tool reads exports from all three, puts every account in one view, and flags admins without MFA, stale privileged accounts, risky OAuth grants and exposed AWS keys.

It runs on your own machine. The review wizard uses PKCE OAuth and CSRF protection, keeps tokens in the macOS Keychain, and writes handoff reports with the sensitive values redacted.

Python, Entra ID, Google Workspace, AWS IAM

Strands PHI Guardrails Demo

Instead of asking the model nicely not to leak patient data, this puts plain rules in front of the agent's tool calls. Six checks run before anything goes out, covering role, purpose of use, data sensitivity, vendor BAA status, PHI in the payload and session limits. Every decision lands in a hash-chained audit log.

I also wrote a red-team suite of policy-bypass attempts. None of them got through. You can try the same rules below.

Python, Strands Agents, Hypothesis

Practice Trust Lab

A fake clinic in Docker. It has a Samba Active Directory domain, three joined machines, file shares and a mock EHR. A Python collector checks it against HIPAA-mapped rules and writes dated evidence packets that hold no patient data. To test it, I planted a compromised npm package and copied records onto desktops, then checked whether my own reporting caught them.

Docker, Samba AD, Python

Small Practice Security Kit

A practice answers intake questions and gets back a 30, 60 and 90 day plan. It covers where patient data lives, which vendors need a BAA and what proof is missing. I wrote it for an office manager, not an IT person.

Python

Service Desk Lab

osTicket in front of a Samba AD domain on my own server. I worked tickets for new hires, lockouts, access changes and offboarding, and wrote a runbook for each. The repo isn't public yet.

osTicket, Samba AD, ITIL 4

SQL injection write-up

OWASP Juice Shop in a local Docker container. I wrote up its login SQL injection like a disclosure report, with a CVSS 3.1 score, screenshots, and steps I reproduced twice from a clean container. It's a known challenge in the app, so I didn't find it first. Nobody else's system was touched.
